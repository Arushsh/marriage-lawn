# Reference Review: alron.in (Mumbai event planner and caterer)

Used for structure and feature ideas only. Do not copy their text, images, logos, layout or graphics.

## What it does well (adopt the idea)
| Idea on alron.in | How we use it |
|---|---|
| Services section (design and decor, catering, corporate events) | Services section: events hosted (wedding, birthday, corporate/official, engagement, social) plus add-on services (decor, catering, DJ, photography) |
| Detailed packages (cake, car, drinks, snacks count, dinner dishes, dessert choices) shown in a pop-up | Packages with grouped inclusions and a "View details" drawer. Owners care about exact inclusions, so list them clearly |
| Menu section with categories (snacks, salad, rice, Chinese) and a "View complete menu" page | Menu section with categories, veg/non-veg filter and a /menu page, plus optional PDF menu download |
| Package dropdown in the enquiry form | Enquiry form gets an optional package field, prefilled when "Enquire" is tapped on a package |
| Trust counters (years, events organized, happy clients) | Quiet stats line from SiteSettings (years, events hosted). Real numbers only |
| Full contact block with several named phone numbers | Primary phone and WhatsApp, plus optional second contact with name |
| "View all photos" link to a gallery page | Already planned (/gallery) |

## What it does badly (avoid)
- Dated look: ornamental leaf graphics, parallax banners, heavy text on top of images.
- About section is a wall of text with inconsistent facts (says 25 years and 38 years).
- No availability calendar, no WhatsApp button, no click-to-call bar on mobile.
- Enquiry form has no event date or guest count, so the owner must call back to ask.
- Typos in copy ("Weddig", "Enggement", "experince"), placeholder stats.
- Only 5 gallery photos on the home page and no virtual tour.
- No SEO structure visible (single page anchors, generic title).

## Our differences (selling points)
- Calendar with real availability, WhatsApp-first enquiry, mobile sticky bar
- 360 degree virtual tour of the lawn
- Clean, photo-led design with short plain copy
- Lead dashboard for the owner

## Section order for our home page
Hero, highlights, about, services, packages, menu, gallery, 360 tour, availability calendar, how booking works, reviews, FAQ, contact.
